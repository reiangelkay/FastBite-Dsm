# FastBite - Manual de Marca y Sistema de Diseño

FastBite es una aplicación móvil para restaurantes que permite a los usuarios realizar pedidos de alimentos de manera rápida, segura e intuitiva. Esta documentación detalla el sistema de diseño **Vibrant Culinary Mobile**, optimizado para una experiencia móvil moderna y apetitosa.

## 🎨 1. Paleta de Colores
El sistema cromático está diseñado para generar contraste y guiar la acción del usuario.

| Color | Hexadecimal | Uso Principal |
| :--- | :--- | :--- |
| **Naranja Principal** | `#FF6B00` | Botones primarios (CTAs), precios, ícono de la app. |
| **Naranja Oscuro** | `#A04100` | Acentos secundarios, íconos de calificación, estados de presión. |
| **Marrón Texto** | `#1C1B1B` | Títulos principales y tipografía de alto contraste. |
| **Marrón Suave** | `#5A4136` | Subtítulos, descripciones y texto secundario. |
| **Fondo Principal** | `#FCF9F8` | Fondo base de las pantallas (limpio y premium). |
| **Fondo Tarjetas** | `#F6F3F2` | Chips de categorías, inputs y tarjetas de productos. |
| **Blanco** | `#FFFFFF` | Contraste para textos sobre botones naranjas. |

## 📐 2. Sistema de Diseño
- **Estilo:** Diseño plano (*flat design*).
- **Bordes:** Redondeados de **8px (8dp)** para una estética suave y moderna.
- **Jerarquía:** Uso de sombras muy suaves para establecer profundidad en tarjetas.

## 🔡 3. Tipografía
La familia oficial es **Plus Jakarta Sans**.
- **ExtraBold (800):** Logotipo textual, títulos de pantallas (32px) y precios.
- **Bold (700):** Nombres de platillos y botones de acción.
- **SemiBold (600):** Encabezados de secciones y etiquetas de formularios.
- **Regular (400):** Cuerpo de texto y descripciones.

## 🖼️ 4. Variaciones del Logotipo
| Archivo | Versión | Uso Correcto |
| :--- | :--- | :--- |
| `logo_blanco.png` | **Positiva** | Logo naranja sobre fondos claros (`#FCF9F8` o `#FFFFFF`). |
| `logo_negro.png` | **Negativa** | Logo crema sobre fondos oscuros o modo noche. |
| `logo_naranja.png` | **Principal** | Logo crema sobre bloque naranja. Usar en **Splash Screen** e ícono. |

## 🚫 5. Usos Incorrectos
- **No** alterar los colores oficiales.
- **No** deformar las proporciones del logotipo.
- **No** rotar ni inclinar el logo.
- **No** usar efectos 3D o sombras paralelas pesadas.
